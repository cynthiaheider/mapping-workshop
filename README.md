# "Playing with Digital History: Making Interactive Maps"

A workshop offered by Cynthia Heider for history undergraduates at the School of Arts and Sciences, University of Pennsylvania.

## Description

Digital mapping tools are a great way to explore and interpret research topics in history from a spatial perspective. In this 1-hour hands-on workshop, we’ll:
- introduce key principles and terminology relating to mapping
- create two kinds of interactive maps using openly available data and a free, easy-to-use tool called [Datawrapper](https://www.datawrapper.de/)
- showcase great digital map examples in historical research and resources to help you learn more.

Please bring a computer. Datasets for mapping will be provided, but feel free to bring your own or any ideas for research objects you’d like to make a map from!

## In this repository
- [Slides](https://github.com/cynthiaheider/mapping-workshop/blob/main/Spring%202026%20playing%20with%20digital%20history%20interactive%20maps.pdf) from the workshop, featuring brief introductions to digital history methods, map terminology, where to find data and some tools to map it.
- [snow-pumps.csv](https://github.com/cynthiaheider/mapping-workshop/blob/main/snow-pumps.csv) & [snow-deaths.csv](https://github.com/cynthiaheider/mapping-workshop/blob/main/snow-deaths.csv), two point-based datasets we will use to create a locator map in Datawrapper. [This data](https://geodacenter.github.io/data-and-lab/snow/) was created by GeoDa at the University of Chicago.
- [nyc-family-size.csv](https://github.com/cynthiaheider/mapping-workshop/blob/main/nyc-family-size.csv), a dataset showing average family size by neighborhood in New York City boroughs and neighborhoods, which we will use to create a choropleth map in Datawrapper. This data was adapted from [2010 census data provided by NYC Open Data](https://www.nyc.gov/assets/planning/download/pdf/data-maps/nyc-population/census2010/t_sf1_p5_nta.pdf) and bourough codes were sourced from this [NYC Open Data dataset].
- [homevalueindex-zillow-states-2019-20.csv](https://github.com/cynthiaheider/mapping-workshop/blob/main/homevalueindex-zillow-states-2019-20.csv), a dataset sourced from the ["Choropleth Map with Datawrapper" lesson plan](https://handsondataviz.org/choropleth-datawrapper.html) in _Hands-On Data Visualization_ by Jack Dougherty and Ilyankou.
